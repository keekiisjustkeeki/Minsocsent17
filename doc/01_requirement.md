# MINSOCSENT WEBSITE

Versi : 1.0

## Tujuan

Website resmi MINSOCSENT untuk kegiatan HUT Republik Indonesia Ke-81 Tahun 2026.

Website digunakan sebagai media informasi kegiatan, proposal digital, surat permohonan dukungan, donasi, dan pendaftaran peserta.

Website harus bersifat statis, cepat, responsif, mudah dipelihara, dan memiliki tampilan profesional.

---

## Target Pengguna

- Masyarakat
- Donatur
- Peserta lomba
- Sponsor
- Pengunjung umum

---

## Bahasa

Seluruh isi website wajib menggunakan Bahasa Indonesia.

Tidak diperbolehkan menggunakan bahasa Inggris pada menu, tombol, maupun isi website kecuali nama teknologi.

---

## Framework

Gunakan:

- HTML5
- CSS3

- Bootstrap 5
- Bootstrap Icons

Tidak diperbolehkan menggunakan framework frontend maupun backend lainnya.
